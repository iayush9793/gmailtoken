100 User Cap Reached on Google Cloud Project

Google Cloud enforces a hard, lifetime limit of 100 users for unverified OAuth projects using sensitive APIs (like Gmail). Because project inboxchecker-488409 has reached this limit, Google blocks new authorizations.

⚡ Fix in 2 Minutes: Create a New Google Cloud Project

Creating a new GCP project gives you a brand-new Client ID with a fresh user quota:

  1. Open Google Cloud Console → Create Project and click Create.
  2. Go to APIs & Services → Library, search for Gmail API, and click Enable.
  3. Go to APIs & Services → OAuth consent screen:
    • Select External → click Create.
    • Fill in App Name & Email, then click Save and Continue.
    • Under Test Users, click + ADD USERS and enter your email address!
  4. Go to APIs & Services → Credentials:
    • Click + CREATE CREDENTIALS → OAuth client ID.
    • Select Application type: Desktop app (or Web app with redirect URI http://localhost).
    • Click Create and copy your new Client ID & Client Secret.
  5. Paste your new Client ID and Client Secret into Step 1 on the left and click Authorize & Get Token!
